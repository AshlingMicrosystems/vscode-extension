# Security policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public GitHub issues.

Email [support@ashling.com](mailto:support@ashling.com) with the subject line **Security: RiscFree VS Code extension**. Include:

- the extension version (from the Extensions view in VS Code);
- your VS Code version and operating system;
- a description of the vulnerability and its impact;
- steps to reproduce it, or a proof of concept.

We'll acknowledge your report and keep you updated while we investigate and fix it. Please give us a reasonable amount of time to release a fix before you disclose the issue publicly.

## Supported versions

Security fixes are released in the latest version of the extension. Keep the extension up to date to get them.
